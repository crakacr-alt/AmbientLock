# Contributing

Проект приветствует маленькие, проверяемые изменения.

Перед pull request:

```bash
gofmt -w .
go vet ./...
go test -race ./...
go build ./cmd/ambient
```

## Принцип проекта

Если новая функция увеличивает coverage, она должна иметь тест или fixture,
который показывает конкретный syscall/сценарий.

Не стоит писать в README, что AmbientLock «видит всё», пока это не подтверждено
архитектурой и тестами.

## Стиль кода

- простые имена;
- стандартная библиотека, если внешняя зависимость не даёт явной пользы;
- комментарии объясняют нетривиальное решение;
- ошибка должна содержать контекст: что именно не удалось сделать;
- секреты не логируются.
