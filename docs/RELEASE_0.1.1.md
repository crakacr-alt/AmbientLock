# AmbientLock 0.1.1

Это первый patch-релиз после полноценного прогона проекта на Linux и GitHub Actions.

Главные исправления:

- корректные относительные пути после смены рабочей папки;
- resolved path для `openat` с directory fd;
- редактирование типовых токенов и паролей в сохранённой командной строке;
- более переносимый workspace-relative lock;
- `--strict-env` для случаев, где список переданных ENV names должен быть строгим.

Версия всё ещё остаётся Linux MVP на `strace`. `enforce` в 0.1.1 проверяет
контракт после запуска и пока не является preventive sandbox.
