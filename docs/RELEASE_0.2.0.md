# AmbientLock 0.2.0

Это первый функциональный релиз после Linux MVP.

## .ambientignore

Добавлен небольшой policy-файл для стабильного шума. Он полезен, когда процесс
каждый запуск трогает кэш, временные файлы или CI-переменные, которые не должны
засорять lock/diff.

Правила применяются одинаково к baseline и текущему запуску.

## JSON report

`diff` и `enforce` получили `--json-report FILE`.

Это позволяет:

- сохранять результат как CI artifact;
- обрабатывать изменения другой программой;
- не парсить человекочитаемый stdout;
- отдельно видеть `changed` и `new_capabilities`.

## Совместимость

Schema `ambient.lock` остаётся 1. Старые lock-файлы продолжают читаться.
